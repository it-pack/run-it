# RunIt 1.0.0-rc.1 — Release-candidate preparation (M15.1)

This document records the M15.1 release-candidate preparation work and the
evidence behind each checklist item. It is the human-readable companion to the
machine-checked backward-compatibility baseline in `tools/api-compat/`.

## Public API freeze

The `1.0.0` public API is frozen at the symbols under these directories
(`tools/api-compat/config.json`):

- `src/Domain`
- `src/Application`
- `src/Contract`
- `src/Adapter`
- `src/SDK`
- `src/Common`

The frozen surface contains **372 public symbols**: **147 interfaces**, **206
classes**, and **13 enums** (counted from `tools/api-compat/api-baseline.json`).
Every concrete class is `final` and interface-backed, and eligible classes are
`readonly`, per `AGENTS.md`. The complete enumerated list is the committed
baseline, not this prose summary.

The stable normalization schema (`docs/normalization-schema.json`) is frozen at
**8 artifact types** (`execution`, `execution_definition`, `activity`,
`activity_definition`, `measurement`, `observation`, `occurrence`, `snapshot`)
and **76 fields** in total.

## Explicit internal namespaces

The following namespaces are **internal** and excluded from the
backward-compatibility guarantee (`tools/api-compat/config.json` →
`internalNamespaces`):

- `ItPack\RunIt\Behavior\` — reusable behavior traits mixed into value objects.
- `ItPack\RunIt\Conformance\` — adapter conformance harness and fixtures.

`Conformance` is shipped and reachable (it lives under the `ItPack\RunIt\` PSR-4
mapping) and the third-party conformance example in M14.8 depends on it, but it
remains internal: consumers must pin the exact RunIt version so the verifiers and
fixtures they use stay aligned. Classes inside a public directory that carry an
`@internal` docblock (for example several `Application\Publication` collaborators)
are likewise excluded by convention, even though the directory itself is public.

This corrects a prior inconsistency in `docs/UPGRADING.md`, which incorrectly
described `src/Application/**` as an internal implementation detail. `Application`
is part of the public surface; only `Behavior` and `Conformance` are internal.

## Removed / abandoned experimental APIs

A repository-wide search found **no** abandoned or experimental APIs:

- No `@experimental`, `@deprecated`, `TODO`, `FIXME`, or `XXX` markers remain in
  `src/`.
- The only `beta` references are data fixtures inside `Conformance\Fixture`
  (`feature_flags` used to exercise verifier behavior), not public API.
- Previously-removed speculative namespaces (`src/SDK/Middleware`,
  `src/Adapter/Callback`) were deleted in the 2026-08-23 refactoring plan and are
  not present.

## Review of public contracts

- **Interfaces (147):** every public interface lives under `src/Contract` or is a
  port/contract in `src/Adapter`/`src/SDK`. The lifecycle/status matrix interfaces
  (`ExecutionStatusInterface::canTransitionTo()`, `ActivityStatusInterface`)
  were reviewed in the ADR-023/ADR-024 refactoring; their signatures are stable
  for `1.0.0`.
- **Classes (206):** all concrete classes are `final` and interface-backed; the
  baseline guards against removed/renamed classes and narrowed signatures.
- **Enums (13):** closed enums (`ExecutionStatus`, `ActivityStatus`,
  `ContextClassification`, `ObservationSeverity`, `MeasurementKind`,
  `SnapshotClassification`, …). Enum-case removals are BC breaks and are guarded by
  the baseline.
- **Attributes (1):** the only PHP attribute is `SDK\Attribute\ExecutedAs`
  (`#[Attribute(TARGET_FUNCTION | TARGET_METHOD | TARGET_CLASS)]`), the
  ergonomic entry point for the `ExecutedCallable` decorator. Its target mask and
  reader (`ExecutedAsMetadataReaderInterface`) are reviewed and stable.
- **Normalized fields (76):** the schema is checked independently of the PHP API,
  so field additions/removals are reported by `composer api:check` even when code
  is unchanged.
- **Occurrence naming:** `OccurrenceType` enforces a lowercase, dot-separated,
  versioned format (`itpack.<domain>.<event>.vN`); PHP class names are rejected as
  implicit types. Convention is documented in `docs/concepts/semantic-model.md` and
  the vocabulary `runit:OccurrenceType`.
- **Default security limits:** `SecurityLimits::default()` and its `with*`
  withers define the bounded cardinality/payload/depth limits; they are frozen and
  covered by unit tests. Deny-by-default redaction is installed by
  `RunItBuilder::build()` unless explicitly opted out (refactoring plan
  2026-08-24).
- **Default failure policies:** publication fails **open** by default
  (ADR-007); `FailSafeArtifactPublisher` routes nested failures to the health
  channel and never replaces the original business exception (ADR-008).
- **Optional dependency constraints:** `composer.json` keeps OpenTelemetry,
  CloudEvents, PSR, Swoole, and OpenSwoole in `suggest`/`require-dev` only; core
  `require` is limited to `php ^8.4` and `just-bases/php-obs-base ^1.0`. No core
  code configures global providers for any optional integration.

## Backward-compatibility baseline

`composer api:baseline` regenerates:

- `tools/api-compat/api-baseline.json` — the frozen PHP API surface.
- `tools/api-compat/normalization-schema-baseline.json` — the frozen schema.

`composer api:check` diffs the current surface against these baselines and exits
non-zero on any break. The M15.1 baseline is the `1.0.0` freeze; `composer
api:check` is a required CI gate (`docs/compatibility.md`).

## Changelog and upgrade guide

- `docs/CHANGELOG.md` gains a `## 1.0.0-rc.1` section summarizing the freeze.
- `docs/UPGRADING.md` "Current release status" now describes the frozen RC surface
  and the baseline-as-stability-contract policy; the internal-namespace statement
  is corrected.

## Publishing the release candidate

The `composer.json` `extra.branch-alias` now maps `dev-main` to
`1.0.0-rc.1.x-dev` so the package resolves as the release candidate on the main
branch. The actual `git tag 1.0.0-rc.1` and Packagist publication are performed
by the maintainer at release time; all preparation (frozen baseline, changelog,
upgrade guide, version alias) is complete.
